## 05 / OPERATING LOOP

```text
GOAL
  ↓
OBSERVE → PLAN → EXECUTE → VERIFY
   ↑                         ↓
   └──────── LEARN ←─────────┘
```

The loop matters more than the first attempt. I prefer systems that expose state, verify their own work and improve through iteration instead of assuming success.
